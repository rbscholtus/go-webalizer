# go-webalizer

A web server log analyser in Go, in the spirit of the classic
[Webalizer](https://webalizer.net/). It reads an Apache access log in Common
Log Format and writes a single `index.html` report with charts.

> [!NOTE]
> This was my Go-learning project. It works well, but I didn't see a realistic
> chance to put it into production, so I stopped developing it.

## What the report shows

- Monthly hits, files, pages, visits, sites and bytes, as bar charts.
- The same figures per day, for the last month in the log.
- Pie charts of HTTP methods and response codes.
- A world map of visitors by country, using the MaxMind GeoLite2 database.
  Lookups run concurrently.

## How it's built

- Log lines are parsed with a parser generated by
  [ldetool](https://github.com/sirkon/ldetool) from
  [`internal/parser/clf.lde`](internal/parser/clf.lde).
- Charts are rendered with [go-echarts](https://github.com/go-echarts/go-echarts).
- The command line uses [urfave/cli](https://github.com/urfave/cli).

## Running it

> [!NOTE]
> These steps are for reference only. I haven't tried them recently.

1. Download `GeoLite2-Country.mmdb` from
   [MaxMind](https://dev.maxmind.com/geoip/geolite2-free-geolocation-data)
   (a free account is needed) and put it in the directory you run from.
2. Run it on an access log:

   ```sh
   go run ./cmd access.log
   ```

3. Open the `index.html` it writes.
